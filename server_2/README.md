<!-- PHASE 1 - CHAT APP -->

1. I want to build a modern chat application
2. Each user can signup / login using their email but we will always take a username whether user signups with google or normal.
3. We will have otp verification.
4. User can login / signup using google
5. User can send invites to multiple people , and the other people will see these invites on their chat app. Consider invite links with expiry + usage limits.
6. If they are not on app , we will prompt user to send themm invite emails to signup.
7. When user logs in we want to store sessions, like user logged in from these devices. And we can log user out of these other sessions on different devices.
8. We can chat one to one, group chats, broadcast chat messages.
9. We can send media files, like images, videos, pdf. Each user / group will have their media section. We should decide file size limit, virus detection, compression of media.
10. We will have group admin settings. Multiple users can be admin of a group, they can remove members, add new members, delete groups.
11. Each indivdual chat, group chat can have different theme.
12. User can select light / dark mode appearance for their web chat app.
13. One of the main features will be scheduling messages in the future, each user can create scheduled messages. User can select individual chats and groups to which user wants to send these messages. User can select date and time. User can select repeatitions, like every monday 5 pm, or select multiple custom days eveery thursday, saturday & sunday 2 pm. And user can configure the message being chat or media to be sent.
14. I want modern chat features like typing indicators, latest messages, archived chats.
15. Online / Offline / Last Seen
16. Notification systems for chat applications
17. Mute Chats / Groups notifications, Pin/Unpin chats
18. We should be able to mention a user using @username in group chats.
