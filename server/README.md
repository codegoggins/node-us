<!-- HOW THE PROJECT FLOW IS -->

1. Building a multi-vendor ecommerce platform
2. I am admin who is building the project
3. Each vendor ( means business ) can have multiple users.
4. Each user can have different roles
5. Each user can have different roles in different vendor organizations.
6. In each vendor organization a user can have only one role. Means a user cannot have different roles under the same business.
7. We will have a vendor signup to take complete details of the business
8. A vendor can upload product details. Can upload different metadata for products like variants colours, sizes, images etc.
9. Vendors will see analytics, orders, refunds, failed payments, how many people added this to cart, conversion rates etc.
10. A vendor organisation admin can create multiple roles to manage different actions
11. Me being an admin can create multiple roles as well. Like to approve products, HR, Staff Head and more with different roles & permissions.
12. I will have a subscription system as well. User can signup on a basic plan. Then a premium plan to get free deliveries, one day deliveries.
